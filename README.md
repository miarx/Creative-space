# Creative-space
Creative Space — це вебзастосунок для перегляду та керування творчими майстер-класами: малювання, кераміки, виготовлення свічок, флористики тощо.

Користувач зможе переглядати майстер-класи, знаходити заняття за назвою, фільтрувати їх за студією, матеріалами та ціною, а також додавати, редагувати й видаляти записи.

За умовою завдання нам потрібна одна головна сутність 
і дві довідникові, пов'язані відношеннями багато-до-одного та багато-до-багатьох.

Сутність 1 — Workshop (головна)
Містить інформацію про конкретний майстер-клас. Саме для неї реалізуємо CRUD.

Сутність 2 — Studio (довідникова)
Одна студія може організовувати багато майстер-класів, але кожен майстер-клас належить одній студії.
Наприклад, студія Art House проводить заняття з акварелі, живопису й скетчингу.
Це зв'язок Many-to-One (N:1).

Сутність 3 — Material (довідникова)
Один майстер-клас може використовувати декілька матеріалів, а один матеріал може використовуватися на різних майстер-класах.
Наприклад, фарби використовуються і для живопису, і для розпису кераміки.
Це зв'язок Many-to-Many (N:M).

Поля головної сутності Workshop
Поле	Тип	Призначення
id	number	Унікальний ID
title	string	Назва майстер-класу
description	string	Детальний опис
price	number	Вартість у грн
date	string (date)	Дата проведення
duration	number	Тривалість у хвилинах
isAvailable	boolean	Чи доступний запис
imageUrl	string	Фото майстер-класу
studioId	number	ID студії (N:1)
materialIds	number[]	ID матеріалів (N:M)
difficulty	enum	Beginner / Intermediate / Advanced
maxParticipants	number	Максимум учасників
format	enum	Offline / Online

Studio — студія

id	number

address	string

Material — матеріал
Поле	Тип
id	number
